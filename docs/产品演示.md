# KnowledgeOS —— 产品介绍与演示说明

> **一句话**：一个 AI 个人知识操作系统，把散落的视频 / 文档 / 图片 / 笔记，自动变成你自己的知识库，还能问答、复习、形成错题本。
> 覆盖 **输入 → 理解 → 沉淀 → 复习 → 应用** 完整闭环。

**在线查看**：在 GitHub 上打开本仓库主页 `README.md`，即可看到完整图文介绍与全部功能截图。

---

## 一、产品定位

KnowledgeOS 不是"又一个 AI 总结工具"，而是一个**覆盖知识全生命周期的个人操作系统**：

- 别人把内容丢给 AI 得到一段摘要，看过就忘；
- 这里把内容变成**可检索、可复用、可复习**的长期知识资产。

适用人群：求职备考、产品 / 工程师等职场人、终身学习者。

## 二、核心功能一览（配图）

### 1. 首页成长看板
知识卡片数、知识空间、复习次数、答题正确率、近 14 天学习趋势，一屏总览。

![首页看板](../screenshots/01_home_dashboard.png)

### 2. 多模态输入 + AI 深度蒸馏
支持 B 站 / 小红书 / 抖音视频、PDF、Word、图片、网页、文本。一键收录后，由多智能体蒸馏成"讲清是什么 / 为什么 / 怎么用 / 常见坑"的结构化知识卡，而不是目录式摘要。

![AI 知识蒸馏](../screenshots/02_capture_ai_distillation.png)

### 3. 个人知识库
用户自定义知识空间（如「AI 产品经理」「Python」「求职」），AI 只给标签建议，分类与归档由你决定。

![知识库](../screenshots/03_card_library.png)

### 4. AI Copilot（基于个人知识库的 RAG 问答）
不是通用聊天：回答**基于你自己的知识库**，并附带**来源引用**，可溯源。支持知识问答 / 知识连接 / 学习辅助三种模式。

![AI Copilot 问答](../screenshots/04_ai_copilot_qa.png)

### 5. 智能复习 + 错题本
按"最近学习 / 指定知识空间 / 薄弱知识"出题，覆盖理解 / 应用 / 面试 / 快速检测四种模式，AI 自动评分，错题自动进错题本。

![复习](../screenshots/05_review_session.png)

![错题本](../screenshots/07_wrong_book.png)

## 三、技术亮点

- **Multi-Agent 协同**：Summarizer（深度蒸馏）、Structuring（概念拆分）、Organizer（标签建议）、QA（RAG 问答）、Orchestrator（状态机编排），五个 Agent 分工协作。
- **双模型成本策略**：轻任务走轻量模型，重任务走深度推理再转结构化 JSON，兼顾质量与成本。
- **Personal RAG 双通道召回**：向量通道 + 关键词通道，解决中文检索召回率问题。
- **去重 / 幂等 / 失败兜底**：避免重复蒸馏，流程可靠。
- **技术栈**：FastAPI + SQLAlchemy + SQLite ｜ React 18 + Vite + TailwindCSS ｜ sentence-transformers + faiss ｜ DeepSeek API。

## 四、如何体验（可演示 Demo）

1. 本地启动后端：`cd backend && pip install -r requirements.txt && uvicorn app.main:app --port 8000`
2. 本地启动前端：`cd frontend && npm install && npm run dev` → 打开 http://localhost:5173
3. 也可以在 `docs/PRD.md` 中查看完整产品设计文档。

> 若要在线演示给老板看，可用内网穿透把前端端口临时暴露成公网链接（如 cloudflare 隧道），**演示结束立即关闭**，避免接口被公网调用消耗 API 额度。
